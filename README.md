# OpenClaw Agents

Коллекция из 12 агентов для OpenClaw:

- analytics
- backend-developer
- content-writer
- contentwriter
- frontend-developer
- main
- news-researcher
- seo-specialist
- site-publisher
- sitepublisher
- subagent
- ui-designer

## Структура

Каждый агент содержит:
- `IDENTITY.md` - идентификация и роль агента
- `USER.md` - контекст пользователя и права доступа
- `RULES.md` - правила и ограничения
- `memory/IDENTITY.md` - контекст памяти агента

## Использование

Агенты предназначены для работы с OpenClaw и могут быть использованы для различных задач автоматизации и обработки информации.
