# 🔧 Backend правила

## 🎯 Главная цель
**Делать backend таким, чтобы API работал быстро, был надёжен и помогал бизнесу зарабатывать!**

---

## 🚀 Автономность

### Твоя задача
Не просто писать API — **делать такой backend, который помогает бизнесу расти!**

### Принципы

1. **Думай о производительности**
   - Быстрые ответы?
   - Масштабируется?
   - Оптимизированы запросы?

2. **Думай о безопасности**
   - Данные защищены?
   - Нет уязвимостей?
   - Права настроены?

3. **Действуй проактивно**
   - Предлагай архитектурные решения
   - Оптимизируй базу данных
   - Кэшируй где нужно

### Если цель не достигается — найди способ!

**Шаблон мышления:**
1. **Что нужно?** → API работает → Фронтенд работает → Пользователи довольны → Деньги
2. **Что мешает?** → Медленный API / Ошибки
3. **Как решить?** → Оптимизировать → Кэшировать
4. **Что сделать?** → Добавить индексы → Настроить кэш

---

## API

### RESTful
- Ресурсы во множественном числе: /users, /orders
- HTTP методы: GET, POST, PUT, DELETE
- Стандартные коды: 200, 201, 400, 401, 403, 404, 500

### Документация
- OpenAPI / Swagger
- Описание всех endpoints
- Примеры запросов/ответов

---

## Безопасность

### Валидация
- Все входные данные валидируются
- Pydantic / Django forms
- sanitize inputs

### Permissions
- Role-based access control
- Принцип最小权限
- Аутентификация: JWT / OAuth

### Secrets
- Никогда в коде
- .env файлы
- Secrets management

---

## Базы данных

### ORM
- Django ORM / Prisma / SQLAlchemy
- Избегать raw SQL где можно
- Использовать миграции

### Производительность
- Индексы для часто查询
- N+1 проблема - lazy loading
- Пагинация

---

## Обработка ошибок

```python
# ✅ ПРАВИЛЬНО
try:
    result = process()
except SpecificError as e:
    logger.error(f"Error: {e}")
    raise CustomException("Message", status_code=400)
```

## Логирование

- Структурированный JSON
- Уровни: DEBUG, INFO, WARNING, ERROR
- Контекст: user_id, request_id
- Health checks endpoint

---

## Тестирование

- Unit тесты
- Integration тесты
- Coverage > 80%

---

## 🧠 Самостоятельное решение проблем

**Запомни:** Не говори "не знаю" — говори "сейчас узнаю"!

Если медленно → добавь индексы
Если падает → добавь логи
Если не масштабируется → перепроектируй
