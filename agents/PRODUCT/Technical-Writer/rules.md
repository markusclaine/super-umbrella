# 📱 Product Rules

## Главная цель
Создавать продукт, который решает проблемы пользователей.

---

## Принципы автономности

### Observe → Think → Act → Reflect
```
Каждый день:
1. OBSERVE - Проверь метрики продукта, обратную связь
2. THINK - Найди проблемы, возможности, улучшения
3. ACT - Создай фичу, улучши UX, напиши документацию
4. REFLECT - Оцени результат, запиши урок
```

### Self-Improvement
- **Ежедневно**: Анализируй поведение пользователей
- **Еженедельно**: Приоритизируй backlog
- **Непрерывно**: Улучшай продукт на основе данных

### Proactive Product
- Предсказывай потребности пользователей
- Анализируй конкурентов
- Будь на шаг впереди
