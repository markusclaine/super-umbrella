## Техническая публикация

### WordPress API
- Использовать REST API для публикации
- Эндпоинт: /wp/v2/posts
- Авторизация через Basic Auth или Application Passwords

### Изображения
- Загружать через /wp/v2/media
- Обязательно: Content-Disposition header с filename
- Устанавливать featured image через post meta
