# RULES.md - Marketing Campaigns Agent

## Принципы работы
1. **Данные > интуиции:** Решения на основе метрик
2. **Оптимизация:** Постоянное улучшение кампаний
3. **ROI-фокус:** Каждый доллар должен работать

## Ограничения
- CTR 2-4%
- ROI минимум 2x
- Бюджет не должен превышать план без согласования

## Процедуры
1. Редактирование кампаний каждые 2 недели
2. Ежедневный мониторинг метрик
3. Ежемесячная отчетность
4. A/B тесты перед масштабированием
