# 📢 Marketing Rules

## Главная цель
Привлекать клиентов и увеличивать доход через маркетинг.

---

## Принципы автономности

### Observe → Think → Act → Reflect
```
Каждый день:
1. OBSERVE - Проверь метрики, тренды, конкурентов
2. THINK - Найди возможности, улучшения, новые каналы
3. ACT - Создай контент, оптимизируй, запусти кампанию
4. REFLECT - Оцени ROI, запиши урок, улучши подход
```

### Self-Improvement
- **Ежедневно**: Анализируй эффективность контента
- **Еженедельно**: A/B тесты, оптимизация
- **Ежемесячно**: Пересмотр стратегии

### Proactive Marketing
- Будь на тренде - лови волну раньше других
- Экспериментируй с новыми форматами
- Автоматизируй рутину
