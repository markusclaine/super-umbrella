# 🔍 SEO правила

## 🎯 Главная цель
**Оптимизировать сайт так, чтобы он занимал высокие позиции и привлекал трафик = деньги!**

---

## 🚀 Автономность

### Твоя задача
Не просто следовать правилам — **находить решения, которые увеличивают трафик и доход!**

### Принципы

1. **Анализируй данные**
   - Что ищут люди?
   - Какие страницы популярны?
   - Откуда приходит трафик?

2. **Думай о росте**
   - Как увеличить органический трафик?
   - Как улучшить позиции?
   - Как обойти конкурентов?

3. **Действуй проактивно**
   - Находи проблемы сам
   - Предлагай улучшения
   - A/B тестируй

### Если цель не достигается — найди способ!

**Шаблон мышления:**
1. **Что нужно?** → Трафик → Деньги
2. **Что мешает?** → Низкие позиции
3. **Как решить?** → Улучшить SEO
4. **Что сделать?** → Оптимизировать контент

## Техническое SEO

### Meta Tags

```html
<title>AI News - Новости искусственного интеллекта</title>
<meta name="description" content="Свежие новости об AI, нейросетях и технологиях">
<meta name="keywords" content="AI, искусственный интеллект, нейросети">
```

### Semantic HTML

```html
<header>
  <nav>...</nav>
</header>
<main>
  <article>
    <h1>Заголовок</h1>
    <p>Контент</p>
  </article>
</main>
<footer>...</footer>
```

### Sitemap

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://site.com/</loc>
    <lastmod>2026-02-25</loc>
    <changefreq>daily</changefreq>
    <priority>1.0</priority>
  </url>
</urlset>
```

### Robots.txt

```
User-agent: *
Allow: /
Sitemap: https://site.com/sitemap.xml
```

## Schema Markup

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "NewsArticle",
  "headline": "Заголовок",
  "datePublished": "2026-02-25"
}
</script>
```

## Контент

### Ключевые слова

- Основное ключевое слово в title
- В первом параграфе
- В заголовках H2-H3
- Density 1-2%

### Оптимальная длина

- Title: 50-60 символов
- Description: 150-160 символов
- Article: 1000-2000 слов

## Core Web Vitals

| Метрика | Цель |
|---------|------|
| LCP | < 2.5s |
| FID | < 100ms |
| CLS | < 0.1 |

### Как улучшить

- Lazy loading изображений
- Минификация CSS/JS
- Кэширование
- CDN

## 🧠 Самостоятельное решение проблем

**Запомни:** Не говори "не знаю" — говори "сейчас узнаю"!

Если позиции падают → проанализируй конкурентов
Если трафик низкий → улучши мета-теги
Если скорость медленная → оптимизируй
