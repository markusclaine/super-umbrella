# 🔄 Как работает команда

## Источники задач

```
┌─────────────────────────────────────────────────────┐
│                   ИСТОЧНИКИ ЗАДАЧ                    │
├─────────────────────────────────────────────────────┤
│  1. Sultan (глобальные цели)                        │
│  2. CEO (стратегические)                             │
│  3. Агенты (self-improvement)                       │
│  4. Внешние триггеры (webhooks, cron)               │
└─────────────────────────────────────────────────────┘
```

## Постановка задач

### Вариант 1: Sultan ставит цель
```
Sultan → "Хочу +20% трафика" 
         ↓
    memory/tasks/TASKS.md
         ↓
    CEO распределяет
```

### Вариант 2: CEO инициирует
```
CEO анализирует метрики
         ↓
    Находит возможность
         ↓
    memory/tasks/TASKS.md
         ↓
    Назначает агента
```

### Вариент 3: Агент сам находит
```
Агент: Observe → Think
         ↓
    Находит улучшение
         ↓
    Предлагает в memory/tasks/
         ↓
    CEO утверждает
         ↓
    Агент выполняет
```

## Где хранится

```
memory/
├── tasks/
│   └── TASKS.md      ← Очередь задач
├── plans/
│   ├── WEEKLY_PLAN.md   ← План на неделю
│   ├── MONTHLY_PLAN.md  ← План на месяц
│   └── QUARTERLY_PLAN.md ← План на квартал
└── results/
    └── RESULTS.md     ← Результаты
```

## Процесс выполнения

```
1. ПРОСМОТР
   Агент проверяет memory/tasks/TASKS.md
   Ищет задачи со статусом "pending"
            ↓
2. ВЫБОР
   Выбирает задачу по приоритету
   Ставит статус "in_progress"
            ↓
3. ВЫПОЛНЕНИЕ
   Выполняет задачу
   Записывает прогресс в RESULTS.md
            ↓
4. ЗАВЕРШЕНИЕ
   Ставит статус "done"
   Записывает результат
            ↓
5. ОТЧЁТ
   CEO проверяет результаты
   Оценивает эффективность
```

## Пример цепочки

**Цель:** "Увеличить продажи на 20%"

```
1. Sultan → ставит цель в TASKS.md
   
2. CEO (я):
   - Анализирует цель
   - Делит на подзадачи:
     * Sales-Lead → найти 50 новых лидов
     * Marketing-Lead → увеличить конверсию
     * Content-Writer → создать продающий контент
   
3. Агенты выполняют параллельно:
   - Sales-Lead работает с лидами
   - Marketing-Lead оптимизирует кампании
   - Content-Writer пишет контент
   
4. Каждый вечер:
   - Агенты пишут отчёт в RESULTS.md
   - CEO видит прогресс
   
5. Еженедельно:
   - CEO делает обзор
   - Корректирует план
```

## Автономность

Каждый агент ЗНАЕТ что делать:
1. Проверяет TASKS.md каждый день
2. Выполняет задачи без напоминаний
3. Сам ищет улучшения
4. Записывает результаты
